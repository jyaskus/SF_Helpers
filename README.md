# SF Helpers Extension

Enhancement suite for Fantasy Grounds Unity's Starfinder ruleset. This extension streamlines repetitive GM/player workflows and fills in quality-of-life gaps while staying close to the stock UI.

## What's Included

1. **Character Ability Pop-Up** – Surfaces the full ability score recipe (base, racial/theme, boosts, gear) so you can track the base starting values, racial modifiers, boosts and item modifiers - rather than simply the total stat score.

2. **Vehicle Helper** – Start by setting the vehicle level which determines all of its metadata. First build the record in FGU, pick grafts (size, type, specials) to define you vehicle, then use this to calculate and populate all of the meta data. This allows for rapid prototyping of new vehicles.

3. **Grenade Auto-Reloads** – Double-clicking a grenade weapon keeps the weapon `uses` node and the inventory stack in lockstep, instantly refunding or deducting grenades as they’re consumed.

4. **Resolve Point usage** - adds a popup with details on the optional rules for Resolve Points introduced in Starfinder Enhanced.

5. **Starship crew action criticals** - adds a popup with details on the optional critical success (natural 20) for actions taken during starship combat from Starship Operations Manual.

6. **Creature Companion Helper** - adds a popup window to see, modify and adjust the creature companions levels, stats, costs to upgrade and skill lists using the Creature Companion rules from Alien Archive(s).
